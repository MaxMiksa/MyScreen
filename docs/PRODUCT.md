# 产品说明

## 窗口快捷键

「设置 → 通用 → 窗口快捷键」默认开启，初始组合为 `Win + W`。托盘运行时按一次打开主窗口，再按一次收回托盘。触发应用快捷键时不会连带弹出开始菜单，单按 `Win` 仍可打开开始菜单。可分别选择组合键和主键，设置会自动保存。关闭开关或退出应用后，原组合键交还给 Windows 或其他应用。

## 统一首页与背景

仅保留新版首页胶囊、设置浮层与连续收展；背景选择只替换单机器／双机器四张底图，不切换组件或设置页。旧界面专属偏好迁移为背景选择后删除旧键，保留现有设置、天气位置、天空偏好与校准。双机器底图的雨水按两块屏幕各自斜边适配；设置展开停用机器水花，保留雨丝和浮层边缘水花。

## 首页天气卡片

天气来源采用免注册／免密钥方案：国内地区优先读取 UAPI 聚合天气。地区与时效核验通过后，有当前天气状况和气温即可显示；缺体感温度或当前降水量不切备用，缺今日温差或未来预报则不显示对应内容。请求失败、地区不符、实况缺失或过期时按原坐标回退 Open-Meteo。雨景由当前雨况触发，缺降水量时使用基础强度，未来降雨不触发当前雨景。

顶部天气卡片按确认的紧凑两栏图实现：524px 宽、至少 100px 高、距顶 48px；左栏两行为彩色 SVG＋当前气温、天气描述＋今日温差，右栏两行为穿衣与出行建议。不显示地区栏，正常天气卡片无位置按钮；更换地区仍从通用设置进入，未选位置时保留选择入口。两栏共用玻璃外框、24px 圆角与四边统一 16px 内缩，当前温度 34px／500 字重、天气与温差 18px、建议 16px／400 字重，天气描述与温差固定同一行，温差不带「今日」；建议各占一行，过长文字省略并可悬停查看完整内容。沿用现有字体与减少动态效果规则，无背景模糊和新增画布。默认隐藏，仅首页 ↓ / S 手动呼出，↑ / W 或 Esc 先收起，再按 ↑ / W 打开设置；设置展开时不显示，不记忆展开状态。

两栏内容左对齐；今日最低／最高气温，以及结合未来三小时天气的穿衣与出行建议仍使用所选地区数据。天气图标随昼夜和天气切换颜色。今日按所选地点时区计算；建议由天气数据规则生成，不伪称官方出行指数。天气查看独立于雨景开关，共用所选位置和单一请求／缓存；未选位置可进入通用设置选择，不自动定位或更改原位置。加载、缺失、失败不伪造天气与建议。

## 天气雨景

天气雨景采用已确认的斜风雨：远近三层细雨随风连续飘落，最大雨量增加四倍，机顶产生短促水珠与少量小弧形飞溅。雨层覆盖底部栏和设置外框，水花跟随形变外框上缘；设置展开即清除并停用机顶水花，收起后恢复。雨丝保持连续，不做阻挡，草坡不生成水花。小雨近乎清透，雨量增大时增强冷灰阴雨色调与克制远雾，夜景减轻压暗，保留电脑和草地清晰度。

手动搜索并选择城市或区县，记住在本机；搜索沿用 Open-Meteo 地名库，支持「南山」「南山区」「深圳南山」，结果和已选位置显示所属城市以区分同名地点。中文地区按已选地区名查询 UAPI，并核对省／市／区县；不自动定位、不承诺街道级实况。雨景只改变软件背景，不改变场景、亮度或色温。降雨时按需创建独立低分辨率雨画布；停雨、隐藏或关闭面板释放，减少动态效果时保留静态氛围。面板可见并使用天气时每 15 分钟刷新；两源均失败明确提示，超过 30 分钟的缓存不继续播放雨。不把天气服务宣传为窗外传感器实测。提供短暂雨景预览，不持久化预览状态。

「通用 → 天气雨景」默认关闭，启用时切到实时换光；搜索后显式选择地点，不定位、不自动选择同名结果。地点、开关沿用本地外观偏好、自动保存及撤销／重做，不增加硬件配置 Revision。预览在 30 秒后、关闭天气或离开实时舞台时结束；关闭面板清除预览。天气优先使用 [UAPI](https://uapis.cn/docs/api-reference/get-misc-weather)，备用 [Open-Meteo](https://open-meteo.com/en/docs)；通用设置的原来源链接跟随实际来源，备用时标注「备用」。

## 天空效果设置

云彩保留原有轻薄流云、蓬松云团、层叠云海与旧版薄云增强；撤下临时首页测试栏及 Takram／体积／卡通候选。仅前三款增加位置分布：原有分布、自然散布、错落高低、弧形环绕、远近云层，可在天空设置中选择，四场景独立保存并支持撤销。旧版薄云不使用位置分布。

所有云彩样式均可选择「随风飘动／原地轻浮」，默认随风向右缓缓移动，粒子云完整离开画面后从另一侧循环；轻浮在原位置附近柔和往返。沿用速度滑条，0 停止，隐藏或减少动态效果时暂停；按场景独立保存，支持预览／撤销／重做，不改云彩样式、星星或硬件。

星空提供「稀疏清晰／满天繁星」，独立调节数量、亮度与闪烁；每颗星使用各自的相位、频率与幅度，只独立明暗变化，不让整片星空同步缩放或呼吸。「闪烁」调节变化强度，0为稳定常亮，减少动态效果时也保持常亮；云彩提供「轻薄流云／蓬松云团／层叠云海」，独立调节浓度与速度。四个场景分别记忆，默认白天云彩、夜晚星星，允许自由搭配。设置支持实时预览与自动保存；沿用现有历史操作。2026-11-15 已批准效果图及布局；用户要求星星与云彩优先采用成熟组件，采用 pmndrs 的 Clouds／Stars 组件，纹理本地打包。

全局排版固定三档：正文、辅助文字与按钮 16px／400、小标题 18px／500、页面标题 26px／600。沿用 Noto Sans / Noto Sans SC；不因窗口宽度增加字号，英文与中文共用档位。所有下拉菜单复用 Radix UI Select，使用玻璃胶囊触发器和中性暖灰圆角玻璃浮层，避免偏蓝黑的独立底色，统一高亮、勾选、键盘选择及焦点恢复；Esc 先关闭下拉菜单，再收起设置。

## 定位与范围

MyScreen 是面向个人使用、兼顾开源分享的 Windows 显示器控制工具。Go 常驻核心负责硬件、计划、专注和边缘滚轮；React 面板按需打开，关闭后核心继续运行，不保留自有 WebView2 界面进程。

- 支持 Windows 10/11 x64 与 Microsoft Edge WebView2 Runtime。
- 主要真机环境是一块 AOC U27G4 外接屏和一块 BOE 笔记本内屏；外接屏用 DDC/CI，内屏用 WMI 调背光。
- 色温面向兼容 SDR 屏幕，通过逐屏 GDI Gamma 调色，不叠加硬件 RGB 调色。
- 不提供 HDR 色温、ICC 色彩管理、应用快捷键或场景快捷键。`2700–6500 K` 是近似冷暖标尺，较暖端受系统 Gamma 范围限制，不代表仪器测量值。

控制只面向前台物理控制台会话中已确认稳定身份的实体屏幕。会话切换、设备映射变化或身份不明时停止写入并等待重新检测；不切换到 RDP 桌面控制其颜色。后台采集画面的像素隔离仍需实机验收。

## 概念与状态

- **正常目标**：面板、场景或时间计划希望屏幕达到的亮度和色温；界面百分比表示正常亮度目标。
- **手动保持**：手动调节后，目标保持到下一计划节点。实时到达节点时从当前目标继续渐变，不跳回旧值。
- **场景**：保存逐屏目标、亮度联动与专注规则的命名组合。
- **时间计划**：按本地时间节点应用场景，并以 `smoothstep` 缓入缓出到下一目标。
- **专注遮罩**：鼠标离开受控副屏达到延迟后覆盖副屏，不改变硬件亮度或正常目标。

面板分别显示检测中、离线、设备错误和保存状态；硬件失败不能显示为成功。当前界面尚未完整区分「目标值 / 写入中 / 硬件读回」。

### 设置浮层与导航

- 已批准的布局：浮层固定为 958×526 DIP，始终居中，不随主窗口缩放；收起胶囊与设置导航保持中心线对齐；底栏与首页场景栏共用 38px 高半透明玻璃选中态，文字左右各留 15px；纯图标为 38×38px 圆形，图文按内容包裹，首页外框与按钮均由内容撑开，不使用固定栏宽或等分空白；外框留白和选项间距随选中框高度按比例计算，四周留白均衡；场景图标采用 19px、2.1px 描边及高对比白色，外框和共用选中框提高边缘对比，避免草地亮部冲淡轮廓；首页外框及共用选中轮廓使用上下对称边缘高光和无垂直偏移阴影，避免等距布局出现上窄下宽的观感；默认窗口 1168×657（16:9，再增大约 10%），最小客户区宽 1024 DIP，避免固定面板被裁切；场景页固定使用舒展行距与分区间距；内容区左右留白 22px、顶部 24px，场景页不单独压缩顶部，使上方圆角附近留白均衡；专注及通用使用独立功能分组与中间细分割线，组内增加选项不跨列；四场景两行两列同屏，保留名称、排序、删除及逐屏亮度／色温；历史按钮组至右／下边缘等距 14px。更多场景或屏幕允许内容区纵向滚动。

## 亮度与颜色

### 逐屏亮度

每块已识别屏幕按各自能力写背光，命令通过串行通道执行。亮度联动开启时，已校准设备对使用按稳定设备标识保存的单调分段曲线，双向插值；未校准设备沿用比例绑定。缺少配对设备时只调整当前屏，不把曲线套到其他屏幕。

当前 `calibrations/aoc-boe-brightness.json` 是本机 AOC/BOE 的个人观感匹配数据：外屏 0% 对应内屏 25%，外屏 95% 以上时内屏保持 100%。按用户决定，同一曲线暂用于所有色温；暖色下未测得独立匹配曲线，不承诺跨色温等亮。个人数据不写入程序默认值。

### Gamma 颜色所有权

- 首次实际调色前保存完整原始颜色表，写入后读回验证；6500 K、恢复原色和正常退出时恢复本应用仍持有的调整。
- HDR、高级颜色、复制显示或 CCD 映射无法确认单一目标时拒绝调色；写入前再次核对前台会话和稳定设备身份。
- 约每 3 秒核对暖色目标：仅退回本应用保存的原色基线时重新应用；检测到其他程序写入的未知颜色时停止调色并提示重新检测，不覆盖外部新设置。
- 恢复记录用颜色 journal 保存到正式配置目录；仅当当前表仍等于本应用最后写入的表时恢复，失败时保留 journal 供后续处理。
- 读回一致仅证明颜色表状态，不能代替真实画面观察。与其他调色软件、夜间模式或游戏同时使用可能冲突。

### 内屏暖色补光

色温变暖会降低白色亮度。只有身份已确认、非主屏、已完成个人校准且当前颜色由本应用持有的内屏可以补光；外接屏不补光。用户正常亮度目标与实际背光目标分开保存，补光不回写滑条或场景权重。

校准按稳定设备标识保存至少两档参考亮度和两个暖度的主观匹配点，范围内插值，超出范围保守延伸。背光到 100% 时提示无法完全补偿，不减弱用户选择的暖度。恢复原色、调色失败、失去颜色所有权或正常退出时先撤回补光；未经校准时不启用。当前本机尚未完成暖色补光校准，跨屏曲线与补偿数据互相独立。

## 场景

场景保存逐屏正常亮度、色温、亮度联动开关、比例权重、专注开关和受控副屏。设备曲线和补光校准独立保存，不随场景复制。

- 默认控制全部副屏；显式空选择表示不控制任何副屏，不等于「全部」。主屏始终排除。
- 离线设备的目标和受控标识按稳定 ID 保留，不映射到其他屏幕。
- 手动切换和计划节点使用同一套场景行为。旧场景缺少行为字段时继承加载时的当前规则，读取不会改写用户文件。
- 新场景捕获当前正常目标与规则，不保存临时遮罩状态。被计划引用的场景不能删除，原因只在按钮悬停提示中说明。
- 场景页可编辑名称与逐屏目标、拖动排序或用键盘移动；撤销、重做作用于共享编辑历史并自动保存。保存后同步快捷面板顺序，保存失败保留草稿和历史。当前页面不展示绑定、专注及受控副屏编辑区，已有规则仍保留。

## 每日计划

每个节点包含时间、场景和渐变分钟数；界面使用统一的全局时长控件批量设置，新增节点继承当前时长，初始默认 30 分钟。统一时长独立保存，即使没有节点也可自动保存、撤销和重做；旧配置若有多种时长则显示「—」，编辑统一控件后再一起改写，不在读取时静默覆盖。`smoothstep` 缓入缓出，0 分钟立即切换，终点不能越过下一节点。跨午夜连续求值；休眠或启动时错过节点按当前时刻直接求值，不补播历史步骤。

进入新节点时只应用一次场景行为并重置专注计时，渐变期间不反复重置。语言、专注暂停状态、场景名称、列表顺序等无关保存不重播节点，也不清除手动保持；修改计划或所引用场景会重新应用相关规则。渐变页拖动或用手柄上下方向键移动时，保留各位置的时间，将场景及其渐变参数移动到对应时间位置，曲线即时更新；场景页排序仅调整场景列表。

## 专注

专注只控制副屏遮罩，不改变亮度。鼠标离开受控副屏达到设定等待时间后显示遮罩；鼠标返回、暂停或副屏存在符合条件的全屏／最大化窗口时隐藏。窗口检测不限于前台，排除最小化、隐藏、其他虚拟桌面的窗口，以及鼠标穿透的提示层和 Windows 截图选区层。最后一个占用窗口结束后重新计算完整等待时间。

桌面状态读取失败时撤下遮罩、丢弃旧坐标并暂停判断；恢复后清除专属提示并重新计时，不沿用未知鼠标位置，也不清除其他错误。该选项只影响遮罩，不修改 Windows 电源或睡眠超时。

## 屏幕边缘滚轮

顶部和底部滚轮各有一个独立开关，默认关闭，自动保存成功后生效，关闭面板仍可用。鼠标位于任一屏幕最顶／最底一行像素时，真实垂直滚轮上滚增加、下滚减少；每格 2 个百分点，高精度滚轮按 120 单位累积。仅接管无鼠标按键、无其他修饰键或只按所选增强键的输入；离开边缘、停顿超过 500 ms、换屏／换边缘／切换增强模式／切换前台应用后清除余量。注入输入、水平滚轮和后台会话放行；触发后不再滚动下方窗口。

- **顶部普通模式**：调鼠标所在屏的正常亮度，遵循联动、校准、补光和手动保持；完成后唤起 Windows 原生亮度浮层，浮层显示系统内屏背光，不映射外屏或补偿前目标。
- **底部普通模式**：每次重新获取当前默认播放设备的主音量，保留静音；完成后唤起系统原生音量浮层。
- **增强顶部**：每格调 100 K（2700–6500 K，上滚更冷）；联动开启时同步支持调色的屏幕，调色失败单独报告。
- **增强底部**：按前台窗口归属调整软件音频会话，每格 2%，多会话统一到一个百分比并保留静音；不改系统总音量，也不回退到主音量。焦点切换后旧请求停止；独占音频、归属不明确或仅由其他宿主代播的窗口不保证支持。

增强按键默认 Alt，可在「设置 → 通用」选择 Alt、Ctrl 或 Shift，自动保存成功后生效；换键使旧队列和余量失效。增强模式复用一个按需创建的原生胶囊浮层，显示色温或应用音量读数与进度；鼠标穿透、不抢焦点，停滚约 1.5 秒隐藏。没有可控会话时隐藏数值条，使用限频托盘通知提示先播放音频；不把缺失会话伪装成 0%。普通边缘滚轮不显示增强浮层，计划和面板滑条不触发原生浮层。

## 语言、启动与退出

- 支持简体中文、English 和跟随系统；切换语言立即预览但不重建草稿，自动保存后用于后续启动。中文系统语言（含繁体）使用简体中文，其他语言回退 English。用户改名的场景保持原样，默认场景名称可随语言变化；前端偏好在加载首屏时读取，保存后用于后续启动。当前托盘菜单固定使用中文。
- 更名后首次启动会继承原有设置、校准和界面偏好，旧配置保留作备份。登录自启只保留 `HKCU` 下唯一 `MyScreen` 项，命令指向正式包中的 `MyScreen.exe --mode native --hardware --production --background`。配置读取、迁移或核心初始化失败时不改动已有自启项。
- 打开面板时按需创建窗口，首页或连接错误可显示后再亮出；连接慢时会显示深色连接页，不闪白。关闭面板销毁 WebView2，不在托盘预开窗口。正式构建无参数打开面板，`--background` 只启动托盘。正常退出移除遮罩、卸载滚轮钩子、撤回补光并恢复原色，保留最新正常亮度。

## 设置保存与失败恢复

- 配置保存到 `%LOCALAPPDATA%/MyScreen/native-settings.json`，颜色恢复记录在同目录；保存前检查 Revision，冲突时旧草稿保留并提示重新载入，不能覆盖新设置。
- 原子写入保留上一版 `.bak`，保存失败保留草稿和 Revision；坏文件、未知 schema 或读取权限错误不允许用默认值覆盖。显式迁移会备份旧配置并保留原文件，不自动改写登录自启。
- 重新检测按稳定标识保留本次会话的色温目标；先恢复原色基线，再应用用户目标。断开设备的目标保留到核心退出。无关设置保存不会让手动保持提前结束。

## 界面设计准则

单机器背景的蒲公英可在通用 → 天空效果中按场景选择「原有轻漂／随风漂浮」，旧偏好默认原有轻漂；双机器背景无独立飞絮素材，不显示此控件、不请求风数据。随风模式优先所选地区当前风向／风力，无风、数据缺失或过期时使用轻柔模拟风；风变化平滑衔接，逐朵起伏、轻转、错速，离屏后从上风侧错时补入。小雨逐朵减少，大雨淡出，雨停渐回。不新增天气请求所有者、画布、纹理、依赖或粒子数量；复用原10朵素材、天气缓存与舞台循环，隐藏／减少动态效果暂停，关闭释放。

飞絮动效：保持原图天空质感，原有悬空蒲公英的左右漂移与上下起伏范围扩大为原来的两倍，同时延长往返周期，保持轻柔飘动速度；四个场景均持续运动，切换场景不重置位置。灰度图只按实际机器外形与草坪边缘分为天空／机器／草地三档，不含飞絮白斑、横向灰带或轮廓外扩保护；空气层复用这一天空轮廓，不另画扩大保护区。仅在制作素材时局部补回原位置天空，不使用整体降噪或重新生图；复用现有画布与渲染循环，隐藏／减少动态效果时暂停。不增加视频、帧序列或常驻全尺寸场景副本。

产品方向是「场景化随手调节」：快捷面板首屏像浮在同一片空间上的玻璃控制带，场景是核心交互，低频规则收进二级入口。用户已确认的四张原创效果图定义方向；界面核对必须使用与当前源码一致的真实截图，不得用旧图或效果稿证明当前状态。

- `frontend/src/index.css` 是唯一设计参数入口；页面不自行新增颜色、字号、圆角或动效数值。系统字体使用 Segoe UI Variable / Segoe UI / Microsoft YaHei UI，场景名使用衬线展示字体；基础字号为 14 / 16 / 24 DIP，间距以 4 DIP 为基础，主操作控件最小高度 40 DIP。
- 单机器背景复用 `frontend/public/scenes/live/*.webp` 与原有实时换光；双机器背景只保留 `frontend/public/scenes/*.webp` 四张原图，以交叉淡入换图。二者共用新版组件、天空与雨景；双机器天空裁切与两块屏幕斜向上边缘按原图位置适配。图片不烘焙文字或控件。
- 新版舞台按需解码当前／目标画面；底图常态只保留一张全尺寸画面纹理、一张灰度权重纹理和一张小型飞絮天空补片图集；独立天空组件复用一张云纹理并通过天空遮罩裁切，切换时临时增加一张目标纹理，结束立即释放。原图 10 朵飞絮以各自速度轻柔左右漂浮，少量上下起伏，四场景位置连续、切换不重置；天空保持原图质感，不做整体降噪。云、星点和飞絮不依赖图片序列，页面隐藏、减少动态效果或舞台卸载时停止循环；不预载 GIF、帧序列或四份解码位图。首页背景、场景栏样式和各场景天空效果偏好不进入 Go 设置、不触发保存流程。
- 设置与舞台使用同一玻璃材质、细边框与浅色控件，不叠加背景模糊；统一 Lucide 图标与 Motion 短反馈。场景胶囊、导航选中项和浮层使用纯圆角。
- 数字默认隐藏，悬停／聚焦／调整时才显示；滑条支持键盘方向键，场景按钮和二级入口有可读的无障碍名称；亮度联动使用连接／断开图标并反映 `aria-pressed`。错误、保存结果、来源、检测与连接状态常驻可见。页面刷新或状态推送不抢焦点、不重置输入。
- 快捷面板与设置页共用固定 16:9 窗口，初始客户区 960 × 540 DIP；拖动边缘缩放时保持 16:9，系统贴靠或最大化后恢复标准比例并居中。不显示原生标题栏和悬停窗口控制条，上边缘保留隐形拖动区；设置占约 82% 窗口宽、74% 窗口高，底部导航仍与首页胶囊同宽同位。中英文切换后检查长文本、无障碍名称和可操作区域。
- 设置内容区直接展示设置项，不再显示顶部宣传句或重复页标题。不显示灰色小字解释、功能定义或重复图注；输入、预览、保存失败和错误状态仍须清楚。正式产品不内嵌或再分发参考站点的 1080P 视频，仅使用本项目的原创本地图片。
- 品牌图形采用 Lucide Sun–Moon 的黑白单色线条、透明背景；`frontend/public/favicon.svg` 是唯一图形源，Windows ICO 由它派生。窗口和托盘随系统深浅色选黑／白版本，设置浮层使用随场景变化的玻璃表面和象牙白选中项。

## 已知边界

- 面板百分比是目标值；目标、写入中、硬件读回的完整区分尚未实现。
- 新版快捷面板的场景切换、展开／收起、外观偏好和背景切换已复验；自动保存、撤销／重做与失败／冲突保护经过浏览器和独立 mock 桌面宿主验收；真实硬件保存仍保留既有后端验收边界。
- 真实比例写入与触顶恢复、休眠重连、热插拔、混合 DPI、HDR、真实 RDP 捕获画面隔离、长时间运行、任意崩溃或断电后的颜色恢复，仍需在对应环境验收。
- 暖色下的跨屏观感一致性、内屏补光启用与完整范围恒亮未验收；用户反馈的内屏轻微偏绿尚未确定发生条件和修正量，当前没有自动校正独立颜色通道。
- 软件音量对真实浏览器子进程、独立音频路由和多会话长期切换的边界需单独核对；原生浮层和轻量增强浮层的外观须以实际系统截图确认。

验证状态见[状态说明](STATUS.md)，工程与维护约束见[开发文档](DEVELOPMENT.md)。

设置页与场景栏共用连续变形的玻璃外框，平滑收展、无回弹；文字和组件保持原尺寸，仅在展开末段／收拢初段淡入淡出。场景按钮仅在收拢末段显现，避免提前重叠；中途反向从当前形状继续。收起立即停止设置交互，保留当前内容与草稿；减少动态效果时直接交接。不使用截图缓存。

实时场景过渡可中断：连续选场景时，从当前混合画面直接转向最新选择，取消过时图片加载，不排队播放中间场景。用显卡内一次性合成衔接，不读回像素、不常驻缓存四张全尺寸图；中断临时最多三张场景纹理，切换结束恢复一张，星星／云彩与雨景仍分别运行。

快速场景输入：方向键／WASD每次都从最新选择递进，三个连续输入应切换三次，不等待React重绘。场景请求尚未完成时，较早请求返回的状态不能把底栏或背景拉回中间场景；请求仍按硬件安全规则串行，最后完成后继续接收外部场景变化，失败保留错误提示并按已知状态恢复。

## 日出／日落计划

在原节点编辑弹层选择「固定时间／日出／日落」，太阳节点允许提前／延后（默认0，最多12小时）；沿用通用设置已选城市坐标，换城跟随更新，不更改已有固定节点。时间轴显示所选地点的天文时刻折算到本机时间，与原计划使用同一时钟。后台本地计算并缓存每天结果，不依赖天气接口或面板开启；极昼／极夜当天缺少的太阳事件不伪造，其他节点继续运行。

按用户确认：拖动太阳节点后转为固定时间；太阳节点参与计划时，仅运行时把渐变缩短至下一节点间隔，不改写设定时长。同分钟只执行一个场景，固定节点优先，其次日出、日落，再按列表顺序；图中说明折叠与缩短。原纯固定计划继续拒绝重复或重叠。自动保存、冲突保留草稿和撤销／重做沿用既有机制。
